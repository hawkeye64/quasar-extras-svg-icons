Use the [GitHub issue tracker](https://github.com/hawkeye64/quasar-extras-svg-icons/issues) for bugs and feature requests.

For icon rendering bugs, please include:

- The icon-set folder.
- The exported icon name.
- A screenshot or short reproduction.
- Whether the issue appears in the source SVG or only after package generation.

For new icon-set requests, include the upstream package or repository link and confirm that the package ships SVG files.
